# GeneLab

Gene's personal portfolio + resume website — showcases his software projects
(CoverCompass, MelCoverCompare, WearCast) and his résumé/CV to visitors
(recruiters, collaborators, etc.).

Start here:

- [`PRD.md`](./PRD.md) — what sections exist, content rules, "done" checklist
- [`CLAUDE.md`](./CLAUDE.md) — project status and rules for working in this repo
- [`DESIGN.md`](./DESIGN.md) — visual design system
- [`ARCHITECTURE.md`](./ARCHITECTURE.md) — tech stack, folder structure

## Status

Design + scaffold complete, page content pending — see `CLAUDE.md` "Current
status" for the up-to-date list of what's built vs. still TODO.

**Resume content and contact info are placeholders.** Anywhere you see
`[Add role/company]`, `[Add contact email]`, etc., that's real content Gene
still needs to fill in — nothing biographical has been invented (see
`CLAUDE.md` for the enforced rule on this).

## Quick start

```bash
npm install
npm run dev
```

## Tech stack

Vite + React + TypeScript + styled-components — same stack as the sibling
projects. Details in [`ARCHITECTURE.md`](./ARCHITECTURE.md).
